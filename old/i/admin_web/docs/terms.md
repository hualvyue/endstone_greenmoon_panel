# 使用须知与使用条款

> 适用版本：GreenMoon 面板 **10.2.3+**
>
> 这一页同时给**服主**和**子插件 / 第三方接入方**看。装之前请花五分钟读完 —— 尤其是加粗的部分。

---

## 一、使用须知

### 1. 这个插件是什么

GreenMoon 面板是一套跑在 Endstone（Minecraft 基岩版服务端）上的**服务器管理工具**，它提供：

- 一个网页管理后台（服务器状态、玩家、白名单、封禁、文件、控制台、多存档切换…）
- QQ 机器人联动（群消息互通、进服播报、远程指令）
- **玩家行为记录**与**区块日志与区域回档**（谁在什么时候、在哪里放了或挖了什么，以及把一片区域恢复到指定时间之前）
- **AI 自动管理**（可配置为纯建议 / 需确认 / 完全放开）
- 对外开放的**第三方插件面板**接口（别的插件可以把自己的设置项挂进来，集中配置）

### 2. 装完之后第一件事：改掉默认密码

面板用 HTTP Basic 认证。**首次启动时生成的密码会打印在服务器日志里**，请立刻在「🔑 账户与安全」里改掉。

> 面板能做的事等同于直接在服务器上敲指令 —— 一个弱密码等于把服务器交出去。

如果只打算在本机或内网用，请把端口绑定到内网地址；需要外网访问时，建议配合反向代理 + HTTPS。

### 3. ⚠ 关于区域回档（最需要谨慎的功能）

- **回档会直接改写世界里的方块。** 它会把目标区域内、指定时间窗内的方块变更逐一还原。
- **回档是异步分批执行的。** 点下去之后它要跑几秒到几十秒，期间不要重启服务器。
- **回档支持「撤销」，但撤销是有条件的：** 撤销依赖回档前保存的现场快照。快照可能被「清理过期记录」删掉，也可能那次回档已经撤销过。这些情况系统会**如实告知失败**，不会假装成功。
- **所以：动用回档前先手动备份存档。** 这是唯一不会让你后悔的习惯。
- 回档前请用「影响面预览」看清会动多少格、涉及哪些人 —— 比盯着一堆坐标点头有意义得多。
- 「区块记录」本身要写数据库。**开启后服务器会有额外的磁盘写入**，记录量大的话请合理设置保留天数。

### 3.1 记录系统有两套（都在「🧱 区块日志与恢复」里配置）

| | **方块日志** | **玩家行为记录** |
|---|---|---|
| 记什么 | 哪一格变成了什么 | 谁做了什么（聊天 / 交互 / 爆炸物…） |
| 用来干什么 | **回档**被破坏的建筑 | 查「刚才谁放 TNT 了」 |
| 颗粒度档位 | 关闭 / 仅破坏 / 破坏 + 放置 | 关闭 / 仅聊天 / 敏感行为 / 全记录 |
| 隐私敏感度 | 只有坐标与方块，较轻 | 含**聊天内容**，较重 |

- **方块日志的颗粒度决定你能回档什么**：选「仅破坏」时只记破坏与爆炸，够用来恢复被炸掉的建筑、占用磁盘最小，但**回档不了「谁偷偷盖的违章建筑」**（放置记录没存）；选「破坏 + 放置」才能完整回档一片区域的改动。
- **改档位只影响之后新产生的记录**，已有记录不受影响。
- 玩家行为记录含聊天内容，属于玩家隐私，请按当地法律法规告知玩家。

### 4. ⚠ 关于 AI 自动管理

AI 接管级别分三档，**请在完全理解后再往上调**：

| 级别 | 行为 |
|:----:|------|
| 0 纯建议 | **什么也不执行**，连只读查询都不跑，只给分析与建议 |
| 1 需确认（默认） | 只读操作直接执行；**不可逆操作只生成待确认提议**，由你在面板上批准 |
| 2 完全放开 | **不可逆操作也直接执行**，不等你确认。执行后会登记撤销记录，在撤销窗口内可一键回滚 |

默认为级别 1。**调到级别 2 之前请确认你已经备份，并且清楚「AI 会自己动手」意味着什么。**

无论哪一档，服主都可以撤回：

- 级别 2 下直接执行的不可逆操作，在**撤销窗口**内可在面板一键回滚；
- **任何一次区域回档**（不论是人、AI 还是别的插件发起的）都能在「🧱 区块日志与恢复」的会话列表里点「↩️ 撤销」撤回 —— 只要那次回档的快照还在。

### 5. 关于第三方插件 / 子插件

- 子插件需要在 `manifest.json` 里声明 `permissions`，不声明默认只能使用游戏侧能力。
- **安装子插件等于在该服务器进程里执行它的代码。** 只装你信任的来源。
- 子插件申请 `mods` 权限 ⇒ 它能安装/卸载其它子插件，这事实上等同**任意代码执行**；申请 `region` ⇒ 它能改写世界方块。这些权限请逐个确认，不要图省事写 `"*"`。
- 远程注册面板需要服主在配置里显式设置 `ext_api_token`；**未配置时该接口一律拒绝**，这是刻意的安全默认。

### 6. 备份建议

- **改任何全局设置、装/卸子插件、动回档之前，先备份存档。**
- 面板配置在插件数据目录；子插件配置在各子插件包内。
- 定期备份整个服务端目录，别只备份世界。

- AI 的建议与操作由第三方大模型服务产生，**可能存在错误**。
- 开启「完全放开」级别意味着你授权 AI **在未经逐条确认的情况下直接执行不可逆操作**。由此产生的任何后果由你自行承担。

## 三、遇到问题怎么办

1. **先看服务器日志**：绝大多数错误会在控制台打印，并附带原因与处理建议（面板刻意把"为什么失败"写进日志）。
2. **「🔑 账户与安全」→ 诊断**：可查看运行状态、线程栈等，便于定位。
3. **反馈时请附上**：面板版本（见本页顶部）、Endstone 版本、服务器日志中相关的报错片段、复现步骤。

🩺 诊断

此页面用于定位「主线程任务执行超时」。若项 tick间隔(tick_gap_ms) 长期明显大于 50ms，说明服务器主线程被拖慢/卡住，完整线程栈会实时打印到服务端控制台（每次超时、主线程 tick>2s 时都会输出）。
